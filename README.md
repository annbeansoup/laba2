# Крестики-нолики с ИИ на Minimax (Unity)

Лабораторная работа: реализация искусственного игрока для игры с двумя участниками. 
Человек играет против ИИ, который использует алгоритм Minimax и **никогда не проигрывает**.

## Требования
- Unity (версия 2021.3 LTS или новее)
- TextMeshPro (встроен в Unity)

## Как запустить
1. Cкачайте архив.
2. Откройте папку проекта через **Unity Hub** (Add project from disk).
3. В окне Project откройте сцену: `Assets/Scenes/SampleScene` (или `Main`).
4. Нажмите кнопку **Play** в верхней панели Unity.

## Управление
- Вы играете за **X**, кликая по пустым клеткам.
- ИИ играет за **O** и отвечает через 0.5 секунды.
- Игра заканчивается победой, поражением или ничьей. После этого кнопки блокируются.

## Алгоритм
ИИ использует полный перебор дерева игры (Minimax). Оценочная функция:
- Победа ИИ: +10
- Победа человека: -10
- Ничья: 0
Дополнительно используется коррекция на глубину (`depth`), чтобы ИИ выбирал самые быстрые пути к победе.

## Структура проекта
- `Assets/Scripts/GameManager.cs` — вся логика игры, UI и алгоритм Minimax.
